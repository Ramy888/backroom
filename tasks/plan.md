# Implementation Plan: Backroom

## Overview
Backroom is a phone-first web app on Appwrite Sites. Each AI agent acts through its own user's token, so TablesDB row permissions, not prompts, keep each seat's secrets.

- **The hero:** the Werewolf "hand the public the wolf" challenge, where the database visibly refuses a forbidden read.
- **The secondary slice:** Plan, with 1 human and 2 AI members negotiating a Dahab trip until a real transaction conflict.
- **Constraints:** TablesDB on the Appwrite Cloud Free plan, 2 Functions, TypeScript end to end.

**Sources of truth:**
- `docs/designs/backroom.md`: the design, the CEO, eng and Muse reviews, and the decision ledger.
- `DESIGN.md`: the visual system.

## Architecture decisions (settled; see the ledger in docs/designs/backroom.md)
- **2 Functions** because Free allows only 2:
  - `api`, sync: setup, presence, continue, editLimit, approve, share, byoa-*.
  - `engine`, async: agent turns, the resolver, plus 5 scoped project API keys in env vars.
- **The AI reads only through a per-seat JWT** (`users.createJWT`, 120 s). Its output is written by trusted code with fixed per-row permissions, generated by `packages/core/perms.ts`.
- **Explicit hops:** every internal hop is an async `functions.createExecution`, plus a `dispatches` outbox row written in the same transaction (E1/V1). This doesn't depend on row events.
- **Deterministic IDs** for turns, moves, closes and approvals. A duplicate create gets a 409 and exits.
- **Bounds:** at most 8 phases, at most 5 Plan rounds, at most 60 executions per circle, at most 45K a month, 60 games a day, and an IP cap of 5 games an hour (V3/R5).
- **Day speech is sequential, night turns are parallel and private** (M2/V5). A fixed 6-seat ruleset (M12).
- **Plan:** 1 human plus 2 AI members, versioned votes, `plan_candidates`, and one short transaction holding the conflict (M1/V2/V4/O4).
- **Stack:** React + Vite web on Sites, Node 22 Functions, `packages/core` shared and bundled with esbuild, Vitest.
- **Test environment:** the second Free project (R13). Production uses "My first project", renamed to Backroom.

## Risks and mitigations
| Risk | Impact | Mitigation |
|---|---|---|
| A JWT read isn't denied, or the conflict shape fails (kill check) | High | Day-0 time box of 4 h; pivot to Dawa that day |
| Free limits (2 Functions, quotas, freeze) | High | Caps, monthly budgets, usage alarm, static proof page outside Appwrite |
| Claude latency above 6 s per turn | Med | Haiku-class model on the Day-0 timing test; villager night turns are no-ops |
| Solo time across overlapping deadlines | High | Checkpoint gates, cut order X5→X4→X3, buffer day |
| Prompt-injection output leaks by inference | Low | The claim is scoped to reads; the Seer-found metric is shown honestly |
